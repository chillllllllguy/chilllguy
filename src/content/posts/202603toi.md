## s214. 細菌繁殖 (Bacteria)

[problem](https://zerojudge.tw/ShowProblem?problemid=s214)

### 思路

紀錄細菌所在的點 接著做bfs往外擴散(存進queue)
另外開一個陣列紀錄已經走第幾個時間點(到t結束)

```cpp
#include <bits/stdc++.h>
using namespace std;
int n, m, l, k;
long long t;
long long ans[200005];
int p[4][2] = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};
pair<int, int> pos[200005];
int main(){
    cin >> n >> m >> k >> t;
    int dis[n][m] = {}, a[n][m];
    queue<pair<int, int>> q;
    for(int i=0;i<n;++i){
        for(int j=0;j<m;++j){
            cin >> a[i][j];
            if(a[i][j]>0){
                pos[a[i][j]] = {i, j};
                ans[a[i][j]]++;
            }
        }
    }

    for(int i=1;i<=k;++i) q.push(pos[i]);
    while(!q.empty()){
        auto[x, y] = q.front();
        q.pop();
        for(int i=0;i<4;++i){
            int nx = x+p[i][0], ny = y+p[i][1];
            if(nx<n&&ny<m&&nx>=0&&ny>=0&&a[nx][ny]==0&&dis[x][y]<t){
                dis[nx][ny] = dis[x][y]+1;
                a[nx][ny] = a[x][y];
                ans[a[nx][ny]]++;
                q.push({nx, ny});
            }
        }
    }
    for(int i=1;i<=k;++i) cout << ans[i] << " ";
}
```

## s215. 紙膠帶 (Tape)

[problem](https://zerojudge.tw/ShowProblem?problemid=s215)

### 思路

sliding window
有缺的話就繼續往右 多的話就從最左邊開始減
記得紀錄是否有動物超過上限

```cpp
#include <bits/stdc++.h>
using namespace std;
int n, lim[26], cnt[26];
int main(){
    cin >> n;
    for(int i=0;i<26;++i) cin >> lim[i];
    string s;
    cin >> s;
    int l=0, king=0, bad=0, ans=0;

    for(int r=0;r<n;++r){
        int x = s[r]-'a';

        if(cnt[x]==0) kind++;
        cnt[x]++;
        if(cnt[x]==lim[x+1]) bad++;

        while(kind>3||bad>1){
            int y = s[l]-'a';
            if(cnt[y]==lim[y]+1) bad--;
            cnt[y]--;
            if(cnt[y]==0) kind--;
            l++;
        }

        if(kind==3){
            if(bad==0){
                int mx = 0;
                for(int i=0;i<26;++i) mx = max(mx, cnt[i]);
                ans = max(ans, mx);
            }
            else{
                for(int i=0;i<26;++i){
                    if(cnt[i]>lim[i]){
                        ans = max(ans, cnt[i]);
                        break;
                    }
                }
            }
        }
    }
    cout << ans << endl;
}
```

## s216. 三仙鬥法 (Competition)

[problem](https://zerojudge.tw/ShowProblem?problemid=s216)

### 思路

因為進行每次運算 數值之差不是沒有變化就是少2
所以可以從奇偶數開始想
先從小的開始推算:
1 1 2 -> 0 2 1(or 2 0 1) -> 1 1 0 -> 0 0 1(C win)
2 1 1 -> 1 0 2(or 1 2 0) -> 0 1 1 -> 1 0 0(A win)
可以看出 只有單一奇數或是單一偶數 該數為answer
也可以往大數推:
2k 1 2 -> 2k-1 2 1 -> ... -> 2 1 2 -> ans = B
2k+1 1 2 -> 2k 2 1(回上面偶數) -> ans = C

```cpp
#include <bits/stdc++.h>
typedef long long LL;
using namespace std;

int main(){
    LL t, a, b, c;
    cin >> t;
    while(t--){
        cin >> a >> b >> c;
        if((a%2==b%2)&&(b%2==c%2)) cout << "A B C" << endl;
        else if(a%2==b%2) cout << "C" << endl;
        else if(a%2==c%2) cout << "B" << endl;
        else cout << "A" << endl;
    }
    /*
        測資:
        偶 奇 奇 -> 偶
        奇 奇 偶 -> 偶
        偶 偶 偶 -> 全
        偶 奇 偶 -> 奇
        奇 偶 偶 -> 奇
    */
}
```
